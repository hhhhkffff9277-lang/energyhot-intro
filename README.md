# EnergyHot 介绍页

EnergyHot 能源产业资讯与事件项目的静态介绍页面。

本仓库用于托管项目介绍页，包含 HTML、样式、交互脚本和概念插图。EnergyHot 产品当前仍处于本地试运行，介绍页公开不代表产品已对外上线。

## 浏览与维护

GitHub Pages 使用 main 分支根目录发布。入口为 index.html，插图存放于 assets/，样式和脚本内联于页面。保留 .nojekyll，以静态文件方式发布。

更新网页时，请同时检查四张插图、三种阅读方式切换、项目阶段演示，以及卡片和页脚处的外链实际打开行为。

插图为概念表达，并非真实项目照片或产品界面。
